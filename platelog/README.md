# PlateLog

Vertical micro-SaaS for HVAC shops: snap the data plate, get the install record, never miss a warranty registration or tune-up.

| Piece | Where | Status |
|---|---|---|
| Problem interviews | `../playbook/SAAS-INTERVIEWS.md` | Run 10 before building anything |
| Data-plate reader demo | `scanner.html`, published as a private claude.ai artifact | Works on your phone while signed in to Claude |
| Presale landing page | `site/` (`build.sh` → `dist/` → Netlify) | Replace `YOUR_PHONE` / `YOUR_EMAIL`, then build and deploy |

Founding-spot signups arrive in Netlify under **Forms → founding**. Turn on email notifications there.
